This project provides a Python prototype for a Constitutional AI Filter Pipeline. The core problem it addresses is the generation of potentially undesirable, harmful, or unaligned content by large language models. While LLMs are powerful, ensuring their outputs adhere to ethical guidelines and specific principles is crucial for safe and responsible deployment.

Our approach implements a multi-stage filtering process inspired by Constitutional AI. Instead of direct human feedback, the model is prompted to critique and refine its own outputs based on a set of "constitutional principles" or rules. This pipeline involves an initial content generation, followed by one or more self-correction or moderation steps where the model evaluates its response against predefined ethical guidelines (e.g., "be helpful and harmless") and suggests improvements. A final refined output is then presented.

To use this prototype, ensure you have a `GEMINI_API_KEY` set in your environment variables. Install the dependencies from `requirements.txt`. Then, simply run `python main.py`. The script will demonstrate the pipeline by taking a user prompt, generating an initial response, critiquing it against a constitutional principle, and finally presenting a refined output.
